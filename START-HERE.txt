OPEN THIS PROJECT IN VS CODE

1. Extract ALL files from this ZIP into a new empty folder.
2. In VS Code, choose File > Open Workspace from File.
3. Select TECUR.code-workspace inside the extracted folder.
4. Install the recommended Live Server extension if prompted.
5. Open dist/index.html, then click Go Live at the bottom of VS Code.
6. In your browser open http://127.0.0.1:5500/

Keep the workspace open. Stop any older Live Server before starting this one.
This workspace already sets dist as the website root. You do not need to move any files or install Node.js to use Live Server.

FILES
- TECUR.code-workspace: opens the correctly configured VS Code workspace.
- dist/: website pages, styles, scripts and pictures.
- scripts/ and data/: page generation and content sources.
- functions/ and security rules: backend project files.
- .vscode/: editor, preview and task settings. Keep this folder.

OPTIONAL PREVIEW
If Node.js is installed, double-click START-PREVIEW.bat or use Terminal > Run Task > TECUR: Preview website (Node.js). This is an alternative to Live Server.

IMPORTANT
Do not open pages with file:// URLs. Do not change /assets paths.
For public hosting, use dist as the published folder. Live admin and direct enquiries still need backend activation as described in LAUNCH-GUIDE.md.
